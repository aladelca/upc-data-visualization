# Slides en Markdown para Warp

Coleccion de presentaciones semanales en Markdown para el curso `Data Visualization` con foco tecnico en `Tableau`.

## Como leer estos decks

- Cada archivo `.md` esta organizado con separadores `---` para marcar slides.
- Los `SVG` locales estan en `./assets/` y se renderizan como imagenes dentro del Markdown.
- El contenido esta pensado para clase, no solo como apunte:
  - marco teorico
  - conceptos clave
  - procedimientos tecnicos
  - laboratorio
  - errores frecuentes
  - referencias
