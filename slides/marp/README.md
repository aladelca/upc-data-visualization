# Decks Marp del curso

Coleccion de presentaciones en `Marp` para el curso `Data Visualization` con enfoque tecnico en `Tableau`.

## Uso recomendado

- Abrir cada `.md` con la extension de Marp en VS Code o exportar con `marp`.
- Todos los decks usan `theme: gaia`, formato `16:9` y paginacion.
- Los assets visuales estan en `slides/marp/assets/`.
- Cada semana incluye una **agenda sugerida de 4 horas** para uso directo en clase.
- La version Marp fue enriquecida con mas teoria, mas estructura docente y mas apoyo visual que la version inicial.
