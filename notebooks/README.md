# Notebooks semanales

Colección de notebooks para la parte práctica del curso `Data Visualization`.

## Estructura

- Un notebook por semana.
- Cada notebook incluye:
  - objetivo de la semana
  - agenda sugerida de 4 horas
  - herramientas teóricas usadas
  - actividad guiada con código
  - exportables para `Tableau`
